# Experimental results (actual Colab run)

The values below were read from `results/metrics.json` generated by the supplied run.

| Model | Test accuracy | Test macro-F1 | Epochs run | Best-validation-loss checkpoint | Runtime |
|---|---:|---:|---:|---:|---:|
| Linear baseline | 0.8386 | 0.8393 | 9 | 6 | 104.04 s |
| Custom CNN | 0.9187 | 0.9182 | 12 | 9 | 140.71 s |

CNN accuracy gain: **8.01 percentage points**. Relative reduction in test error compared with the linear baseline: **49.6%**.

The CNN training ran for 12 epochs, but the checkpoint with the lowest validation loss is from epoch 9. The evaluation script restores that checkpoint before measuring the held-out test set.

## Important notes
- The run used device `cuda` and random seed `42`.
- Test set size is 10,000, kept separate from training and validation.
- `class_metrics_cnn.csv` derives per-class precision/recall/F1 from the included confusion matrix.
- Do not commit the dataset to Git. Consider leaving checkpoints and large output artefacts out of the public source repository unless your instructor explicitly expects them; they are included in this ZIP for reproducibility and demo convenience.
